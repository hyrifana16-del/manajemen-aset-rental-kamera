LensLedger 
Merupakan sistem pengelolaan atau manajemen aset tetap untuk rental kamera. 
Web ini membantu mencatat transaksi kemera, inventoris kamera, jurnal penyusutan aset, dan fitur perhitungan penyusutan menggunakan metode unit cost. 
Demo:https://hyrifana16-del.github.io/manajemen-aset-rental-kamera/frontend/
